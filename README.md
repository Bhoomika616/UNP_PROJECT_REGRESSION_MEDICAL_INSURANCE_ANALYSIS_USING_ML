# UNP_PROJECT_REGRESSION_MEDICAL_INSURANCE_ANALYSIS_USING_PYTHON
I did this project in collaboration with UNP, where I developed an Insurance Analytics model using Python and Machine Learning to predict medical insurance charges. The project involved analyzing factors such as age, BMI, smoking status, gender, children, and region. I used Pandas and NumPy for data preprocessing and performed exploratory data analysis to identify patterns in insurance costs. Additionally, I developed and compared **Linear Regression, Decision Tree, and Random Forest** models using different evaluation metrics. The tuned Decision Tree model achieved the best performance with an **R² of 0.89**. This project strengthened my skills in Python, data preprocessing, machine learning, model evaluation, and data-driven analysis.
